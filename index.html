Biblioteca de exercícios

O nome do arquivo vira o nome do exercício (ex.: military_press.png → MILITARY PRESS). Se a pasta tiver uma subpasta por exercício, o nome da subpasta é usado. As imagens são reduzidas automaticamente para o tamanho da ficha. Você também pode arrastar imagens para cá. As imagens da pasta imagens do site aparecem sozinhas, marcadas como “do site”.

Histórico de fichas

Abra uma ficha antiga para reaproveitar, ou use "Próxima semana" para copiar a atual com as datas avançadas.
Backup

Os dados ficam só neste navegador. Exporte um backup de vez em quando (biblioteca, histórico e dados fixos num único arquivo .json) e importe-o para restaurar ou para usar em outro computador. Importar junta com o que já existe: nada é apagado.
