# Imágenes de los ejercicios

Pon aquí una imagen por ejercicio. Cuando se publica la web, aparecen solas en la Biblioteca y en la ficha.

- **El nombre del archivo es el nombre del ejercicio:** `military_press.png` → MILITARY PRESS. `_` y `-` se convierten en espacios.
- **Las carpetas son las carpetas de la biblioteca:** `CORE/ANTIROTADORES/press pallof.jpeg` → PRESS PALLOF, dentro de CORE › ANTIROTADORES. Al añadir un ejercicio a la ficha, primero se elige la carpeta y luego el ejercicio.
- **Formatos:** PNG, JPG, GIF o WEBP (HEIC no: los navegadores no lo muestran). Lo ideal es hasta unos 800 px de ancho y pocos cientos de KB.

## Añadir imágenes desde la web de GitHub

1. Abre esta carpeta (`imagens`) en el repositorio y entra en la carpeta que quieras.
2. **Add file → Upload files**, arrastra las imágenes y pulsa **Commit changes**.
3. Netlify vuelve a publicar solo en 1–2 minutos. Recarga la app.

Una imagen subida desde la propia app (pestaña Biblioteca) se queda solo en ese navegador y tiene prioridad sobre la de aquí.
