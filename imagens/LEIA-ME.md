# Imagens dos exercícios

Coloque aqui uma imagem por exercício. Depois que o site é publicado, elas aparecem na Biblioteca e na ficha automaticamente.

- **O nome do arquivo vira o nome do exercício:** `military_press.png` → MILITARY PRESS. `_` e `-` viram espaço.
- **Ou use uma subpasta por exercício:** `military_press/foto.png` → MILITARY PRESS.
- **Formatos:** PNG, JPG, GIF ou WEBP. O ideal é até uns 800px de largura e poucos centenas de KB.

## Adicionar imagens pelo site do GitHub

1. Abra esta pasta (`imagens`) no repositório.
2. **Add file → Upload files**, arraste as imagens e clique em **Commit changes**.
3. O Netlify publica de novo sozinho em 1–2 minutos. Recarregue o app.

Uma imagem enviada pelo próprio app (aba Biblioteca) fica só naquele navegador e tem prioridade sobre a daqui.
